
PROJECT: Real-Time Cryptocurrency Anomaly Detection Using Apache Kafka

AI TOOL USED: ChatGPT

PURPOSE:

--------------------------------------------------
1. PROJECT DESIGN AND ARCHITECTURE
--------------------------------------------------

Prompt summary:
Help me design a real-time cryptocurrency anomaly detection project using Apache Kafka, Python, Binance WebSocket data, SQLite and Streamlit.

Understand the system architecture, components and data flow.

--------------------------------------------------
2. KAFKA PRODUCER IMPLEMENTATION
--------------------------------------------------

Prompt summary:
Help me implement a Python Kafka producer that collects live BTCUSDT and ETHUSDT trade data from Binance WebSocket streams and publishes the events to the crypto-trades Kafka topic.

Purpose:
Implement real-time market data ingestion.

--------------------------------------------------
3. KAFKA CONSUMER IMPLEMENTATION
--------------------------------------------------

Prompt summary:
Help me implement a Kafka consumer using confluent-kafka to receive cryptocurrency trade messages and process them using Python.

Purpose:
Implement real-time event consumption.

--------------------------------------------------

--------------------------------------------------

Prompt summary:

Identify unusual price movements and trading volumes.

--------------------------------------------------
5. DATABASE INTEGRATION
--------------------------------------------------

Prompt summary:
Help me integrate SQLite with the Kafka consumer to store cryptocurrency trades and detected anomalies.

Persist trade records and anomaly alerts.
